# Task API

A simple CRUD API built with **Python** and **FastAPI** for managing a to-do list.

The project supports creating, reading, updating, and deleting tasks.  
Task data is stored **in memory**, so all changes are lost when the server restarts.

## Features

- Create a new task
- Get all tasks
- Get a task by ID
- Update a task
- Delete a task
- Input validation
- Error handling with HTTP status codes
- Interactive Swagger UI documentation

## Tech Stack

- Python
- FastAPI
- Uvicorn
- Pydantic
- Swagger UI
